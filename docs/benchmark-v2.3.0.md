# 会话管理 (Session Manager) v2.3.0 历史库基准测试

同一台 Windows x64 机器，Node.js 26.4.0、SQLite 3.53.2。固定生成 10,000 个会话和 100,000 个正文分块，模拟宿主分页服务，通过插件实际路由请求数据并序列化响应。每个场景启动 20 个新进程，各运行一次首次请求和一次完全相同的请求。v2.3.0 的重复请求带上首次返回的快照。系统文件缓存未清空。

表中耗时单位为毫秒。每格按 v2.2.0 → v2.3.0 排列，内存为各场景测得的最大进程 RSS（MiB）。两版运行时段不同，首次请求耗时还受机器负载影响。

| 场景 | 首次 P50 | 首次 P95 | 重复 P50 | 重复 P95 | 峰值内存 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 会话列表 | 161.11 → 240.6 | 177.84 → 292.2 | 119.04 → 0.11 | 142.27 → 0.36 | 112.8 → 89.7 |
| 短中文「膜」 | 430.41 → 769.05 | 509.16 → 1058.56 | 371.28 → 0.18 | 429.37 → 0.32 | 274.6 → 137.6 |
| 代码 node::get() | 458.04 → 751.62 | 591.03 → 919.79 | 411.24 → 0.16 | 486.81 → 0.29 | 275.9 → 137.6 |
| 词中片段 rmaliz | 467.81 → 786.65 | 563.23 → 975.65 | 406.26 → 0.16 | 485.23 → 0.24 | 273.8 → 137.3 |
| 多词 cobalt kernel | 448.55 → 570.68 | 573.71 → 714.48 | 380 → 0.18 | 494.59 → 0.49 | 274 → 134 |
| 单条预览 | 228.74 → 121.09 | 331.73 → 224.77 | 187.48 → 81.35 | 224.29 → 116.27 | 105 → 66 |

四类搜索分别命中 589、527、435、345 个会话，逐 ID 与样本真值一致。新版遍历全部 200 页无重复或遗漏。列表首屏从 10,000 个会话减至 50 个。预览从 100 次 ListConversations 降至 1 次 GetConversation。

快照内重复检索和定向预览获益最明显。本次测量中，首次正文片段检索耗时上升、峰值内存下降。首次检索还需建立会话快照并在独立工作线程读取正文。多关键词基准使用两版均能命中的语料；跨消息匹配另由功能测试覆盖。

复测命令为 `node tools/benchmark-history.mjs --samples 20`。
